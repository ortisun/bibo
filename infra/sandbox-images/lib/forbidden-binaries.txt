# Names of programs that no sandbox image may contain, one per line.
#
# Two scripts read this file, so the build and the test cannot drift apart:
#   lib/harden.sh   deletes every executable or symlink with one of these names while building
#                   the agent and verify images.
#   tools/fsaudit.py  fails the test when any image still has an executable file or a symlink with
#                   one of these names, anywhere in its file system.
# Blank lines and lines that start with # are ignored. A name is an exact base name; a trailing
# star (perl*) is the only wildcard and is read the same way by find and by fnmatch.
#
# Version control. The sandbox has no git: version control runs on the host against a git
# directory the sandbox cannot reach (docs/security/sandbox-policy.md section 6.2). A GitHub
# command line would also carry a way to reach GitHub.

git-shell
git-upload-pack
git-receive-pack
git-upload-archive
git-lfs
gh
hub
svn
hg
