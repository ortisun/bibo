# Documentation

This folder is the source of truth for the project. The documents come first and the code
follows them: before a change to the code, the documents that describe it are updated.

| Section | What it holds |
|---|---|
| [Specifications](specifications/README.md) | What the project must do, and why. |
| [Architecture](architecture/README.md) | How the project is built, with its diagrams. |
| [Decisions](adr/README.md) | One record for each decision that is costly to reverse. |
| [Guides](guides/README.md) | How a person does a task with the project. |
| [Reference](reference/README.md) | The exact facts: commands, settings, interfaces. |
| [Knowledge base](knowledge/README.md) | What the project is: its features, flows, business rules, terms, integrations and constraints. |

Every document has one place in one of these sections and a link from the index of its section.
