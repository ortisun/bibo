# Decision records

One record for each decision that is costly to reverse or that a future maintainer will ask
about. Each record states the context, the options weighed, the reason each option lost, the
choice and its costs. Number the records in order, `NNNN-short-title.md`, and never reuse a
number. To change a decision, write a new record and mark the old one as replaced. List each
record below with a link, its decision and its status.
