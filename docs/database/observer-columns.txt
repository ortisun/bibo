# Every column of every table that the group factory_observer can read (migration 2026-11-20-002900_observer_role, and
# the troubleshooter's own tables of migration 2026-11-20-003000_troubleshooting_runs, every column operational).
#
# Format: <table> <column> <class> [# why, for a sensitive column]. Class is "operational" (granted) or
# "sensitive" (never granted: a request text, a specification, an issue body, a token or token digest, a key, a
# signature or bound hash, a chain hash, free text written by a person, a person's identity, an event payload).
#
# The test observer_columns in crates/mcp_postgres/tests/observer_role.rs migrates a database and fails when:
#   * the group can read a column this file does not mark operational (a grant nobody classified);
#   * a column this file marks sensitive is readable by the group;
#   * a table the group can read has a column this file does not list (a new column nobody classified).
# A new column is therefore denied until a person classifies it here and, if operational, grants it in a migration.
